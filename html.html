HyperText Markup Language

HTML is the standard markup language used to create and structure web pages. It defines the meaning and structure of web content through a system of elements represented by tags. HTML is platform-independent, meaning the same HTML code can be displayed on any device with a web browser.

Key Characteristics

  • Defines the structure and content of web documents (headings, paragraphs, links, images, tables)
  • Uses tags enclosed in angle brackets: content
  • Is interpreted (rendered) by the web browser, not compiled
  • Works alongside CSS (styling) and JavaScript (interactivity) to form the front-end of web applications
  • Latest standard is HTML5, which added native support for audio, video, canvas, and semantic elements
