Uniform Resource Locator

A URL is the complete address used to identify and locate a specific resource on the Internet. It provides all the information a browser needs to retrieve a document, image, or any other resource

Parts of a URL

Example URL: https://www.library.strathmore.edu:443/resources/books/index.html?id=42&lang=en#section2

Note: A URL is a specific type of URI (Uniform Resource Identifier). URNs (Uniform Resource Names) are another type of URI that provide globally unique names without necessarily pointing to a web resource.
