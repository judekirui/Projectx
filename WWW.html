World Wide Web

The World Wide Web is a wide-area hypermedia information retrieval system that provides universal access to a vast array of documents distributed across the Internet. It was invented by Tim Berners-Lee in 1989 and became publicly available in 1991. The Web operates on top of the Internet, utilizing the HTTP protocol to enable communication between clients (web browsers) and servers (websites). It allows users to access and share information through web pages, which can contain text, images, videos, and other multimedia content. The Web has revolutionized how we access and share information, making it an integral part of modern life.

Key Characteristics

  • Wide-area: The WWW spans the entire globe, connecting systems on every continent.
  • Hypermedia: Contains text, images, audio, video, and hyperlinks connecting documents to one another.
  • Information retrieval: Web browsers allow retrieval of pages simply by clicking hyperlinks or entering addresses.
  • Universal access: Platform-independent — any computer with a browser can connect to any web server.
  • Open publishing: Anyone can publish a web page, making virtually any topic accessible.
